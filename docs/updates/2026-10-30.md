# 30 Oct 2026: State and city pickers

**Short version:** the app's address form gets its states and cities from the API now. It no longer carries a hardcoded list. The old list had only 6 states, so shoppers anywhere else could not save an address.

**Who has to act:** the customer app team.

---

## New APIs (no token needed)

### 1. All states

```
GET /api/customer/states
```

```json
{
  "data": [
    { "name": "Andaman and Nicobar Islands", "is_union_territory": true },
    { "name": "Andhra Pradesh", "is_union_territory": false }
  ]
}
```

All 28 states and 8 union territories, A–Z. The same list also comes back as `states` on `GET /api/customer/reference`.

### 2. Cities of one state

```
GET /api/customer/cities?state=Tamil Nadu
```

```json
{
  "state": "Tamil Nadu",
  "data": ["Ambur", "Arakkonam", "Chennai", "..."]
}
```

- `state` can be in any case. `haryana` works, and the reply spells it `Haryana`.
- A missing or unknown `state` gets a `422` error on `state`.
- The list has about 1,250 towns across India.

## Change to saving an address

`POST /api/customer/addresses` and `PUT /api/customer/addresses/{id}`:

- **`state`** must be a name from `/states` when `country` is `IN` or missing. Otherwise the request fails with a `422` on `state`. It is saved in the list's spelling: `"tamil nadu"` is stored as `"Tamil Nadu"`. It is still optional.
- **`city`** is still free text. Nothing changed here.

## What the app should do

1. When the address form opens, call `/states` and fill the state dropdown.
2. When a state is picked, call `/cities?state=…` and fill the city dropdown. Put a search box on it, because some states have 100+ cities.
3. **Keep a "Type your city" option.** The list is the census town list, so not every village is in it.
4. When saving, send `state` exactly as `/states` spells it.

## Where the data lives

`resources/data/indian-cities.json`. To add a missing city, add it there under its state.

The list started from the Census 2011 town list. It was then cleaned up:

- Broken names were fixed. For example, "KathUrban Agglomeration" became Kathua.
- Old names were replaced with current ones: Gurugram, Prayagraj, Haridwar.
- Missing places were added: Ghaziabad, Navi Mumbai, and the towns of Sikkim, Ladakh and Lakshadweep.
